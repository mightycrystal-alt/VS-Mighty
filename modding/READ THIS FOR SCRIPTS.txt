ShardEngine HScript support

Put .hx or .hxc scripts in the matching folder:
  scripts/mainmenu/  MainMenuState
  scripts/title/     TitleState
  scripts/freeplay/  FreeplayState
  scripts/options/   OptionsState
  scripts/song/      PlayState

The same folders can be used inside a mod folder. Gameplay scripts can also
be placed in the active song folder at data/<song-name>/.

Scripts run only while their matching state is active.

Available callbacks:
  onCreate(state)
  onUpdate(elapsed)
  onStepHit()
  onBeatHit()
  onSectionHit()
  
  (idk why i made those we could just use create and update whatever)

Custom note scripts go in custom_notes/ and use the note type filename:
  custom_notes/(note).hxc

Custom note callbacks:
  onCreate(note)
  onUpdate(note, elapsed)
  goodNoteHit(note)
  opponentNoteHit(note)
  noteMiss(note)

Scripts may use either the HScript callback names above or the ones used in lua names:
  create/onCreate, update/onUpdate, stepHit/onStepHit,
  beatHit/onBeatHit, sectionHit/onSectionHit, event/onEvent
